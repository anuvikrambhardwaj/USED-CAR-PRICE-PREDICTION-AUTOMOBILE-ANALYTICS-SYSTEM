Pipeline Architecture Core Stages
1. Missing Value Imputation

Median imputation for skewed numerical attributes (mileage, engine size, hp); Mode imputation for categorical features (fuel, transmission).

2. IQR Outlier Treatment

Capping anomalies beyond $[Q1 - 1.5 \times IQR, Q3 + 1.5 \times IQR]$ using Winsorization to preserve data volume while stabilizing variance.

3. Data Cleaning & Encoding

Automated duplicate row purging, irrelevant ID removal, One-Hot Encoding for categories, and StandardScaler transformation.

4. Model Training & Comparison

Multi-model evaluation comparing Linear Regression, Ridge, Decision Tree, Random Forest, and Gradient Boosting with $R^2$, RMSE, and MAE.
